# Проверка версии 0.1.0

Дата: 2026-09-25.

В текущей среде выполнено:

- Python 3.12: установка проекта в отдельное virtualenv и проверка CLI.
- `python -m unittest discover -s tests -v`: 22 теста пройдены,
  11 интеграционных тестов пропущены (isolate не установлен).
- Настоящий testlib 0.9.45: компиляция фиксированного демонстрационного чекера
  через g++, проверка правильного, неверного и избыточного ответа.
- `python tools/smoke_http.py`: запуск Gunicorn, HTTP-вход, открытие задачи,
  отправка исходника в очередь и чтение статуса через API; сервер после теста остановлен.
- Проверка Python-синтаксиса через compileall и JavaScript через `node --check`.
- Создан `examples/demo-contest.zip` с двумя задачами и настоящим testlib.h.

Не проверено в этой среде:

- Реальное исполнение присланных решений через isolate, cgroups и дисковые квоты.
- Интеграционные вердикты AC/WA/CE/RE/TLE/MLE/OLE на целевом Ubuntu-сервере.
- Установка предоставленных systemd/nginx-конфигураций на сервер пользователя.
- Реальные пакеты конкретного пользователя и нагрузочное тестирование.

Для этих проверок есть `pcms doctor`, `tests/test_integration.py` и инструкция
в README. Нельзя считать тесты с имитацией песочницы подтверждением её изоляции
или точности измерения ресурсов. В проекте нет автоматического обхода isolate.

## Установщик Ubuntu

Добавлены 9 тестов: отдельный nginx-сайт, запрет перезаписи чужого файла,
сохранение соседних конфигураций, конфликт домена в многострочной директиве,
откат при ошибке nginx -t/reload, отсутствие include, проверка домена и служб.
Все 9 пройдены. Проверен синтаксис Bash/Python и встроенного кода создания
администратора. Проверены параметры umask Gunicorn.

Установщик не запускался с root на реальном Ubuntu-сервере. Установка apt-пакетов,
сборка выделенного isolate, loop-mount с квотами, systemd и выпуск сертификата
здесь не испытаны. Скрипт сам выполняет doctor и интеграционные тесты до
публикации сайта на целевом сервере.

- Статически проверены все 13 задач и 587 входных тестов предоставленного контеста:

  Содержимое контеста не добавлено в репозиторий.
- Локальные тесты: 34 пройдены; 14 тестов isolate пропущены.
- Добавлены проверки генерации ответов с имитацией sandbox, отказа эталона и
  атомарного отката, фоновых импортов, Java-классов и testlib4j, профилей языков,
  миграции БД, зависимостей групп и лучшей посылки в таблице.
- HTTP smoke Gunicorn/login/submit/status пройден после исправления регрессии
  CLI-импорта готового пакета без isolate.
- Серверные тесты дополнены компиляцией/запуском Java и генерацией ответов

основных C/C++/Python/Java, не прошли runtime-проверку. Полную совместимость со
всеми языками/версиями Polygon эта проверка не подтверждает.

## Исправление доступа к профилям

По серверному отчёту все 14 интеграционных тестов прерывались в setUp: каталог
/etc/pcms-lite имел 0700, поэтому pcms не мог даже проверить наличие JSON.
Установщик теперь предоставляет группе pcms проход к каталогу и чтение профилей,
сохраняет root-only пароль и проверяет доступ от pcms до интеграционных тестов.
13 тестов установщика и 10 тестов подготовки пройдены локально, включая
регрессию прав, сохранность содержимого профилей и диагностику недоступного файла.
Повторный запуск интеграционных тестов на сервере ещё требуется.

## Старый testlib без stdint.h

В заголовке из проблемной задачи используется uint64_t без явного include.
При компиляции C++-чекеров добавлен `-include stdint.h`; исходники пакета
и параметры компиляции участников не изменяются. Синтетический воспроизводящий
пример проверяется настоящим g++: обычная сборка падает, сборка чекера проходит.
Код пользовательского архива на хосте не исполнялся.
